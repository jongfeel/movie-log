# 🎬 Movie Log

본 영화를 관람일 기준으로 기록합니다. 포스터를 누르면 감상을 적은 issue로 이동합니다.

## 감상 포인트

영화를 보고 나면 아래 세 가지를 기록합니다.

1. **영화 제목의 의미**: 제목이 영화 속 어떤 장면, 대사, 설정에서 왔는지
2. **영화 포스터 해석**: 포스터가 담은 장면과 구도가 무엇을 말하는지
3. **영화 속 배경**: 영화의 장소와 실제 촬영지는 어디인지

### 왜 이렇게 적나요?

제목과 포스터는 영화를 보기 전에 가장 먼저 만나는 정보입니다. 영화를 본 뒤 다시 들여다보면 처음과는 다른 의미가 보입니다.
배경은 영화를 보면서 "저기는 어디일까?" 궁금해지는 부분이라, 실제 장소를 찾아보며 영화를 한 번 더 떠올리게 됩니다.
줄거리나 별점보다 이 세 가지를 적는 것이 영화를 더 오래 기억하는 방법이라고 생각합니다.
